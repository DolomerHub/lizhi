# lizhi
[![Static Badge](https://img.shields.io/badge/Python-3.14-3776AB?style=flat-square&logo=python&logoColor=yellow)](https://www.python.org/downloads/release/python-3147/)

Lizhi (from the Chinese word named lychee, Chinese translation is: 荔枝) is a unofficial Twitch Python wrapper.

# Requirements
twitchio 3.3.2+ or twitchAPI 4.5.0+
Python == 3.14.7
