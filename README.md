# lizhi
[![Static Badge](https://img.shields.io/badge/Python-3.14-3776AB?style=flat-square&logo=python&logoColor=yellow)](https://www.python.org/downloads/release/python-3147/)

Lizhi (from the Chinese word named lychee, Chinese translation is: 荔枝) is a unofficial Twitch Python wrapper.

# Requirements
twitchio 3.3.2+

Python == 3.14.7

# Get Started
Start cloning this GitHub repository by using Git:

```bash
git clone https://github.com/DolomerHub/lizhi
cd lizhi
```

Then install the dependencies with Python:

```bash
pip install -r requirements.txt
```

Or if you want a better one:

```bash
python -m pip install -r requirements.txt
```
